# 白浜家族旅行 しおり

2泊3日で巡る南紀白浜＆すさみ満喫ツアー

## 旅行基本情報

| 項目 | 詳細内容 |
| --- | --- |
| 日程 | 11/21(金) 〜 11/23(日)［2泊3日］ |
| 宿泊先 | 1泊目：大江戸温泉物語Premium 白浜御苑、2泊目：TAOYA白浜千畳 |
| 住所 | 白浜御苑：和歌山県西牟婁郡白浜町1011 / 白浜千畳：和歌山県西牟婁郡白浜町1680-1 |

## ドライブ行程マップ

| 日程区分 | 移動ルート・経由地 |
| --- | --- |
| 往路（1日目） | 大阪方面（自宅） → 阪和自動車道（和歌山南スマートIC） → 【昼食】道の駅 四季の郷公園 → 阪和自動車道（海南東IC） → 海南市わんぱく公園 → 紀勢自動車道（南紀白浜IC） → 【観光】千畳敷 → 【宿泊】大江戸温泉物語Premium 白浜御苑 |

## 旅のワンポイントメモ

- **ICの乗り降り**：1日目の昼食は「和歌山南スマートIC」、わんぱく公園は「海南東IC」、3日目の自然博物館は「海南IC」の利用がスムーズです。
- **防寒対策**：11月下旬の海沿い（特に千畳敷やすさみ沿岸）は風が冷たくなりやすいため、着脱しやすい防寒着を携行してください。
